# Student Portfolio Website

## Project Description
A student portfolio website built using Python, Django
templates, HTML, and CSS.

## Purpose
To display student information, skills, school projects,
and contact details.

## Target Users
Students, teachers, and visitors who want to view a portfolio.

## Features
- Home, About Me, Skills, Projects, and Contact pages
- Reusable navbar and footer
- Responsive layout
- Django template inheritance

## Technologies Used
Python, Django, HTML, CSS, Git, and GitHub

## Installation Instructions
1. Install Python and Git.
2. Clone this repository.
3. Open the project folder in VS Code.
4. Create and activate a virtual environment.
5. Install requirements.
6. Run database migrations.
7. Start the development server.
8. http://127.0.0.1:8000

## Commands
- python -m venv venv
- venv\Scripts\activate
- python -m pip install -r requirements.txt
- python manage.py migrate
- python manage.py runserver



## Challenges and Solutions
 A blank page appeared because the template files were empty or misnamed. I fixed the file names and added the content.
